# 安装脚本设计模式

  基于现有的 Redis 安装脚本设计模式，为 ${SERVICE_NAME} 创建完整的安装脚本，要求：

  **变量定义：**

- `SERVICE_NAME`: 服务名称（如 redis、etcd、mongodb 等）
- `SERVICE_DISPLAY_NAME`: 服务显示名称（可选，用于日志输出）

  **核心功能：**

  1. 支持原生安装和 Docker 安装两种方式
  2. 包含预安装检查、安装、卸载、状态检查和信息显示功能
  3. 自动处理依赖项和系统配置

  **系统集成：**

  1. 在 `scripts/make-rules/deploy.mk` 中添加 make 规则：

     ```makefile
     .PHONY: deploy.install.${SERVICE_NAME}
     deploy.install.${SERVICE_NAME}:
      @scripts/installation/${SERVICE_NAME}.sh install
     ```

  2. 在 `scripts/installation/install.sh` 中导入脚本
  3. 在 `manifests/env/env.dev` 中添加环境变量配置

  **技术要求：**

  1. 遵循项目的错误处理模式 (`set -o errexit/nounset/pipefail`)
  2. 使用 `proj::util::sudo` 进行权限提升
  3. 支持 Mac 和 Linux 平台
  4. 包含完整的日志输出和错误处理
  5. 避免重复下载和安装

  **脚本结构：**

- 环境变量定义
- `proj::${SERVICE_NAME}::install()` - 原生安装
- `proj::${SERVICE_NAME}::uninstall()` - 原生卸载
- `proj::${SERVICE_NAME}::docker::install()` - Docker 安装
- `proj::${SERVICE_NAME}::docker::uninstall()` - Docker 卸载
- `proj::${SERVICE_NAME}::pre_install()` - 预安装检查
- `proj::${SERVICE_NAME}::status()` - 状态检查
- `proj::${SERVICE_NAME}::info()` - 信息显示
- 命令行调用支持

  **验证要求：**
  运行四个核心命令验证功能：

- `make deploy.install.${SERVICE_NAME}`
- `make deploy.uninstall.${SERVICE_NAME}`
- `make deploy.install.docker.${SERVICE_NAME}`
- `make deploy.uninstall.docker.${SERVICE_NAME}`

  **使用示例：**

  ```bash
  # 使用时将 SERVICE_NAME 替换为具体服务名
  # 如：redis、etcd、mongodb、kafka 等

  # 示例：创建 MongoDB 安装脚本
  SERVICE_NAME=mongodb
  SERVICE_DISPLAY_NAME="MongoDB"

  # 生成的函数名：
  # proj::mongodb::install()
  # proj::mongodb::docker::install()
  # make deploy.install.mongodb
  ```

  参考 `scripts/installation/redis.sh` 和 `scripts/installation/etcd.sh` 的实现模式。
