## 🚀 快速验证命令

```bash
# 1. 检查服务状态
./scripts/installation/service.sh status all

# 2. 生成测试日志  
echo '{"msg":"test message"}' >> logs/apiserver/app.log

# 3. 验证字段映射修复
curl -s "http://localhost:9428/select/logsql/query" -d 'query=_msg:"test message"'

# 4. 监控系统健康
curl http://localhost:13133/health
curl http://localhost:8888/metrics | grep otelcol_
```
